# BMW Global Flagship — Standalone Edition (Pure HTML5 / CSS3 / Vanilla JS)

## Overview
This standalone edition is an ultra-lightweight, zero-build-step version of the official-grade BMW Global Flagship web application.

### Key Highlights
- **Zero Dependencies**: Requires no Node.js, npm, webpack, vite, or external servers.
- **Double-Click & Run**: Simply open `index.html` directly in any modern browser (Chrome, Safari, Edge, Firefox, Arc).
- **Offline Capable**: All graphics, telemetry, 360° procedural canvas rotator, and acoustic audio synthesis engine run 100% locally.
- **Web Audio API Engine**: Synthesizes real-time Hans Zimmer BMW IconicSounds Electric and BMW M TwinPower Turbo V8 engine revs via native browser Web Audio API without needing external MP3 audio assets.
- **Interactive 360° Studio**: Fluid mouse and touch drag through 36 rotational angles with live paint finish changing, rim options, and auto-spin.
- **Fleet Showcase**: Full fleet filtering (BMW M, BMW i Electric, BMW X Series SAV, and Sedans).
- **Test Drive Concierge**: Local reservation validation with instant booking pass generation.

## File Structure
- `index.html` — Clean semantic HTML5 layout with dark luxury styling.
- `style.css` — High-contrast dark mode (#080808, #121214), BMW Electric Blue (#0066B1), and BMW M tricolor accents.
- `script.js` — Vanilla JavaScript procedural canvas rendering, state management, and Web Audio synthesis.
- `README.md` — Usage documentation.
